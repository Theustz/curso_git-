git init . -> criar um repositório git na pasta atual
git status -> mostrar o status do trabalho 
git add nome_arquivo -> adicionar arquivo para ser commitado (sempre usar ele)
git commit -m "msg" -> faz commit do quie estava para ser commitado (git  add)
git log -> para ver os commits 
git diff -> mostra alteração no arquivo 
git reset -> altera o estado para não commit 
git checkout -b -> cria uma copia do projeto 
ps: -b é para criar um branch nova se quiser so navegar entre elas apenas o git checkout
git branch -> para olhar quantas copias tem 
git branch -D -> para excluir branch sem ter que autorizar
